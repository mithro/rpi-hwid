A Raspberry Pi hardware identity probe (what a Pi wears on its header, what powers it, which network interfaces are soldered down, which FPGA board it hosts), a collector that runs it over ssh across a fleet, and a generator for print-ready labels. Install python3-rpi-hwid, which also provides the rpi-hwid command. The package is architecture all (pure Python), so it installs on any Raspberry Pi OS or Debian machine; Raspberry Pi OS follows Debian's codenames.

python3-spiflash, the SPI flash part database the label generator names flash chips from, is here too: it is not in Debian, so each publish copies it from spiflash's own repository, verified against that repository's signature and signed with this repository's key, and python3-rpi-hwid installs from this repository alone.
